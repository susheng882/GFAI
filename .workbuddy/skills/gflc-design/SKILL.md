# GFLC 设计系统

这个产品的界面只有一套规则。**新增页面不要另写一套样式，只用这里的 token 和类名。**

## 产品与方向

给考研和自学的人用的学习工作台：把 PDF、视频、试卷变成能背的卡片和题库，并在仪表盘上盯进度。

- **性格**：温和、精确、像一本被用过的记录本
- **世界**：纸、墨、荧光笔 —— 不属于"云控制台"
- **签名细节**：一条荧光笔痕（`.hl`），只标"今天要做多少"这一个数字
- **两处 moment**：主趋势图、背诵卡翻面。其余一律安静

## 阶梯

| 类别 | 只允许这些值 |
|---|---|
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32 |
| 字号 | 10.5 / 11.5 / 12.5 / 13.5 / 14.5 / 20 / 22 / 44 |
| 字重 | **400 / 500**（没有 600、700） |
| 圆角 | 6 控件小 / 8 输入按钮 / 12 卡片 / 14 面板 |
| 行高 | 导航与列表 34 / 表格行 44 |
| 栅格 | 12 列，gap 16 |
| 页边距 | 24 / 32 |
| 动效 | `cubic-bezier(.22,1,.36,1)`，140 / 180 / 320ms |

## 硬规则

1. **一屏 ≤ 7 个数据块**，其中只有 1 个是 hero（字号 ≥ 40px），其余 ≤ 22px。
2. **一屏只有 1 个实心主按钮**。次级动作走 `.btn.outline` / `.btn.ghost`。
3. **颜色只表意**：强调色用于"当前选中 / 主图线 / 关键数字"；红色只表示错误。
4. **不用渐变、发光、彩色阴影**。深度靠表面层级 + 发丝线。
5. **数字一律等宽**（`font-variant-numeric:tabular-nums`），时间戳用 `--mono`。
6. **每个数据块必须有 0 数据形态**：一句说明 + 一个可点的动作，不能只显示空表格。
7. **图标只用 `ICONS` 里的内联 SVG**：18px / 1.5 stroke / currentColor，不用 emoji、不用字符。
8. **文案不写操作说明**。"双击卡片改数据"这种话不进界面；标题写"这是什么"，不写"怎么操作"。
9. **不给短句加句号**，不用感叹号，不写"真实数据："这类前缀。
10. 动效只过渡 `color / background / border / opacity / transform`，绝不 animate 宽高、top、left。

## 组件解剖

**卡片**
```html
<section class="card">        <!-- 20px 内边距，12 圆角，1px 发丝线 -->
  <div class="sh">标题<span class="meta">12 项</span></div>
  …
</section>
```

**hero 数字**
```html
<div class="lab">今天要复习</div>
<div class="big"><span class="hl">27</span><small>张卡片</small></div>
<div class="delta"><b>+5</b> 相比昨天 · 预计 18 分钟</div>
```

**主图**：平滑折线（Catmull-Rom → 贝塞尔）+ 3 条发丝网格 + 5% 面积 + `vector-effect="non-scaling-stroke"`。柱状图只有峰值上色，0 值画 2px 刻度。

**表格**：表头 11.5/400/元信息色，行高 44，hover 用暖 accent，首列 500。

**空状态**：`emptyState({icon,title,desc,action})`，图标 40px 圆角容器 + 标题 + 一句说明 + 一个动作。

## 验收（改完自查）

- [ ] 一屏数据块 ≤ 7，hero 唯一
- [ ] 主按钮计数 = 1
- [ ] 所有间距是 4 的倍数
- [ ] 字重只有 400/500
- [ ] 强调色 ≤ 4 处，无渐变无发光
- [ ] 每个数据块有 0 数据形态
- [ ] 1440 / 768 / 430 三档无横向滚动
- [ ] 深色下卡片与背景能分辨，正文对比 ≥ 7:1
- [ ] 没有 emoji 当图标、没有操作说明式文案
