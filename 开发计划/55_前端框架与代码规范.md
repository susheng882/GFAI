# 55 · 前端框架与代码规范（GFLC proto）

> 日期：2026-11-28　｜　适用：`gflc/web/src/proto/`（唯一前端）

---

## 一、技术栈（对齐 43 号技术报告）

| 层 | 选型 | 说明 |
|---|---|---|
| 框架 | React 19 + Vite 7 | 函数组件 + hooks，无 class 组件 |
| 样式 | Tailwind CSS（Apple 白 token 在 styles/tailwind.css） | 不引 antd，自绘组件体系 |
| 路由 | react-router-dom 6 | BrowserRouter，14 路由 + guard |
| 图标 | NavIcons.jsx 内联 SVG | 统一 1.5 stroke、12-16px、currentColor |
| 数据 | mock/index.js（107 对象） | 纯前端，接口契约见 53 号文档 |
| 动效 | CSS animation（ease-apple / fade-up / slide-in） | ≤260ms，reduced-motion 保护 |

## 二、目录结构

```
src/
├── proto/
│   ├── main.jsx          # 入口（唯一，index.html 指向）
│   ├── App.jsx           # 路由 + 登录守卫
│   ├── AppShell.jsx      # 侧栏(可拖拽228/64) + 顶栏 + 命令面板
│   ├── NavIcons.jsx      # 全部图标（内联 SVG）
│   ├── ui.jsx            # 通用组件：Card/SectionTitle/Badge/Btn/Progress/Empty/Kpi/MeterRow/KeyCap/Divider
│   ├── mock/index.js     # 107 个数据对象（唯一数据源）
│   └── pages/            # 14 页面，命名 Page 后缀
└── styles/tailwind.css   # Apple 白 token + gf-* 语义类
```

## 三、命名规范

| 项 | 规则 | 示例 |
|---|---|---|
| 页面文件 | `XxxPage.jsx`（PascalCase + Page 后缀） | DashboardPage.jsx |
| 组件 | `Xxx`（PascalCase），导出具名或默认 | `export function Card()` |
| state | camelCase + 语义 | `activeNote` / `aiTidyOpen` |
| handler | `on` + 动词 | `onPickNote` / `onToggle` |
| 常量 | UPPER_SNAKE | `MINI_KEY` / `STATUS_TONE` |
| mock 对象 | camelCase 复数 | `noteList` / `videoTabs` |
| CSS 语义类 | `gf-` 前缀 | `gf-card` / `gf-num` / `gf-nav` |

## 四、代码风格（Prettier 已配）

- 单引号、分号、行宽 120、尾逗号
- JSX 属性多行时每个属性一行
- 条件类名用 `cx()`（ui.jsx）拼接，不手写三元嵌套
- 数字一律 `gf-num`（tabular-nums），时间/百分比等宽对齐
- 文案用中文、简洁、无句号结尾、无感叹号

## 五、组件使用规则

| 场景 | 用 | 不用 |
|---|---|---|
| 卡片容器 | `Card`（16px 圆角白底） | 裸 div + 手写边框 |
| 区块标题 | `SectionTitle`（title/sub/action 三段） | 手写 h2 + span |
| 状态徽标 | `Badge tone=…`（neutral/brand/ok/bad/warn） | 彩色 pill |
| 按钮 | `Btn variant= solid/line/text size= xs/sm/md` | 裸 button |
| 进度 | `Progress value tone height` | 手写 bar |
| 空态 | `Empty dashed`（虚线框版） | 一行灰字 |
| 指标 | `Kpi` | 手写大数字 |
| 快捷键 | `KeyCap` | 纯文本 ⌘K |

## 六、动效规范

- 入场：`animate-fade-up`（240ms ease-apple）——每页根元素用一次
- 抽屉：`animate-slide-in`（260ms cubic-bezier(.32,.72,0,1)）
- hover：`transition-colors duration-150/200 ease-apple`
- 禁：`transition-all`、`hover:scale`、循环动画（pulse 除外——只用于"进行中"状态）
- 全部受 `prefers-reduced-motion` 保护（tailwind.css 已有）
