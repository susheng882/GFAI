## 2. 市面做法对标（决定布局与交互）

| 需求 | 对标产品 | 可迁移的做法 |
|---|---|---|
| 内联双链 | **Obsidian / Roam / Logseq** | `[[标题]]` 自动补全；点开跳转；右侧「反向链接」分区显示「哪些笔记提到了我」；图谱可选 |
| 笔记树 + 文件操作 | **Obsidian 文件树 / 飞书文档目录** | 左侧树（项目→科目→笔记），右键菜单：重命名/移动/复制/删除/导出 MD；拖拽移动 |
| 概览仪表盘 | **Grafana / Plausible** | 一屏「指标带 + 趋势 + 明细」；不放大段文字；数字优先、图次之 |
| 任务看板 | **Linear / Trello** | 卡片=学习任务，状态列（待办/进行中/已完成），点卡片才展开 AI 内容 |
| 刷题背诵 | **Anki** | 一套数据两种模式：刷题（选择/判定）与背诵（翻卡），同一入口切换 |
| 解析去噪 | **MinerU / Unstructured** | 版面分块 → 去页眉页脚/页码/水印 → 按标题层级聚合 → 语义分块 |

结论：**不新造概念，全部贴现有成熟交互**；视觉继续用项目纸墨系统，不引入新设计语言。

## 3. 目标布局

```
侧栏（固定）
├── 概览        ← 原「仪表盘」，只放系统/学习指标
├── 学习任务    ← 原「AI 看板」，卡片=任务，AI 内容点击才生成
├── 笔记        ← 三栏：目录树 ｜ 编辑器 ｜ 反向链接 + 大纲
├── 资料        ← PDF/Word/MD/TXT 上传与解析
├── 刷题背诵    ← 刷题 / 背诵 双模式
├── 视频
├── 任务
└── 设置        ← 供应商/模型/转录器/Cookie/诊断/监控
```

**笔记页三栏**：左 240px 目录树（右键文件操作）；中 编辑器/预览（支持 `[[双链]]` 自动补全）；右 280px「反向链接 + 本文大纲」。

## 5. 验收标准（可测）

| 编号 | 验收项 | 判定 |
|---|---|---|
| V1 | 开发模式免登录 | `DEV_AUTH_BYPASS=true` 时直接进主界面；登录接口仍可用；`APP_ENV=prod` 时强制关（启动日志 ERROR） |
| V2 | Word/MD/TXT 解析 | 上传 `.docx/.md/.txt` → 任务 ready → 生成 chunks；标题层级进 `heading_path`；PDF 回归不退化 |
| V3 | 双链 | 笔记 A 写 `[[笔记B]]` → 点击跳转 B；B 的右栏出现「A 引用了本文」；改名后链接仍可解析（按标题匹配） |
| V4 | 监控 | 设置→监控显示：任务分布、队列/并发、最近失败（可展开错误）、模型调用次数与成本合计 |
| V5 | 目录树 | 项目→科目→笔记三层；新建/重命名/移动/删除后树即时更新 |
| V6 | 文件操作 | 复制生成副本；导出 `.md`；删除二次确认；操作有成功/失败提示 |
| V7 | 解析去噪 | 页眉页脚/页码/水印行被剔除（抽样 3 份 PDF 对比 chunk 数下降且正文不丢） |
| V8 | 解析提速 | 50 页 PDF 端到端 ≤8s（当前实测 0.4s/3 页）；题库 20 题 ≤60s |
| V9 | 概览 | 一屏 5 个数据块：今日待复习、连续天数、本周产出、资料/笔记数、任务健康；无大段文字 |
| V10 | 学习任务 | 卡片可拖状态；AI 内容点击才生成（不再自动跑）；刷题/背诵同一入口切换 |

## 6. 风险与约束

| 风险 | 处理 |
|---|---|
| 关登录变成生产事故 | 仅 `DEV_AUTH_BYPASS` + `APP_ENV!=prod` 生效；启动打 WARNING；prod 下强制忽略 |
| docx 解析引入新依赖 | 已装 `python-docx`，不新增；失败降级提示，不静默 |
| 双链全局扫描变慢 | 按标题建索引（`notes.title`），反链用 `LIKE '%[[标题]]%'` + 上限 50 条 |
| 仪表盘改版影响已有数据 | 只改前端视图，不动 `/dashboard/stats` 字段 |
