## 一、技术栈与架构

| 层 | 技术 | 说明 |
|---|---|---|
| 后端 | Python 3.11 + FastAPI | 异步，15 个 router 模块 |
| ORM | SQLAlchemy 2.x + Alembic | 22 张表，迁移链 0001–0011 |
| 数据库 | SQLite（生产可切 PostgreSQL） | `DATABASE_URL` 可配 |
| 前端 | React 19 + Vite 7 + Tailwind CSS（Apple 白设计语言，自绘组件体系 ui.jsx + NavIcons） | 15 页面纯 mock，SPA，零第三方 UI 库 |
| 状态 | React hooks + useSyncExternalStore | 任务坞用外部 store |
| 鉴权 | HttpOnly Cookie Session | 7 天 TTL，samesite=lax |
| 任务队列 | 进程内 runner + 轮询 | 7 种后台任务，无独立队列服务 |
| AI | 方舟 Ark + DeepSeek 双通道 + BGE 向量 + whisper ASR + 必剪云端 | 三档路由，契约校验+纠正重试 |

### 架构分层

```
web/ (React 19 + Tailwind SPA · src/proto 唯一前端)
  ├─ ui.jsx / NavIcons.jsx（自绘组件体系）
  ├─ pages/ 15 页面（100% mock 数据）
  └─ styles/tailwind.css（Apple 白 token）
        │
app/main.py (FastAPI, /api 前缀)
  ├─ routers/ (15 模块, 110 路由)
  ├─ services/ (业务逻辑: cards/notes/video/embedding/query_opt/...)
  ├─ ai/ (模型通道: router/deepseek/ark/mock)
  ├─ core/ (config/errors/security/budget)
  ├─ worker/ (runner + handlers/ 7 任务)
  └─ models/ (22 张表)
```

## 三、技术亮点

1. **视觉 OCR 双通道**：方舟优先、失败回落 DeepSeek；页级缓存（prompt 版本化）、像素保护（单边 ≤8150 + 总像素 ≤60M）、并发 4 路渲染。
2. **预算护栏**：成本账本 + 日额度（tokens/成本双重），视觉链路只告警不硬拦（避免大文件中途失败）。
3. **掌握度双轨对齐**：卡片/题目各自 mastery，`/mastery/reconcile` 两步安全对齐（预览只读 → 执行只改 mastery）。
4. **同源成卡**：笔记 `正面 :: 背面` 行 → 卡片锚点，hash 变更提示，改源不丢卡。
5. **批量导入可观测**：`bulk_ingest.py` 采集大小/耗时/速度/token/CPU/内存，`render_perf_report.py` 出六面板 PNG。

## 四、技术债（按危害排序）

| # | 债务 | 危害 | 证据 | 建议 |
|---|---|---|---|---|
| T-1 | **进程内任务队列** | 无持久化、无横向扩展、进程重启丢任务 | runner 是进程内轮询 | 生产切 Celery/RQ 或至少持久化队列 |
| T-2 | **视觉链路只记账不拦截** | 预算可被批量任务突破 | 视觉记账不走 generate_json 的硬拦截 | 加「软阈值 + 告警」，产品决定是否硬拦 |
| T-3 | **SQLite 单文件** | 高并发写锁、单点 | 当前 DATABASE_URL 默认 sqlite | 生产切 PostgreSQL |
| T-4 | **注释过期** | models.py 头写「7 张表」实际 22；Task.type 注释列 video_parse 实际已拆 | `_audit` §问题 3/5 | 注释随代码更新 |
| T-5 | **前端目录职责不清** | pages/ 混入 4 个子组件 | `_audit` §问题 6 | 子组件移 components/ |
| T-6 | **decks router 无 prefix** | 路由风格不一致 | `_audit` §问题 1 | 统一加 prefix |
| T-7 | **API 版本 0.2.0** | 与功能规模不符 | main.py:101 | 升到 1.0.0 |

## 六、建议路线（技术侧）

2. **中期（本月）**：清技术债 T-4/T-5/T-6/T-7（注释/目录/prefix/版本号），成本低收益是工程健康度。
