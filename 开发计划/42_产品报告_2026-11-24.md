## 一、产品定位

**一句话**：把考研/自学人手上的资料（PDF、视频、题库、笔记），变成能背、能练、能复习的东西。

**核心价值主张**：不是「又一个题库 App」，也不是「又一个背单词 App」，而是**资料 → 物料的转化引擎**。

| 维度 | 说明 |
|---|---|
| 目标用户 | 考研（尤其 408/数学）与自学人群，手上堆了大量 PDF 讲义、网课视频、真题 |
| 核心痛点 | 资料太多看不完、看完记不住、练完不留痕 |
| 差异化 | 全链路闭环：**资料 → 笔记 → 卡片 → 刷题 → 复习**，竞品多只做其中一环 |
| 明确不做 | 自建词库、自建海量题库、社交排名、插件生态、桌面客户端 |

## 二、功能全貌（六大模块）

### 2.1 资料与解析
- 上传 PDF / Word / MD，自动解析分块（文字层直出；扫描件自动切视觉 OCR）
- 文档详情页作为「二级枢纽」：一份资料的掌握度、笔记、卡片、题目一屏聚合
- 题库文件（PDF 试卷）导入 → 视觉识别抽题 → 结构化入库

### 2.2 笔记（双链知识库）
- Obsidian 式三栏编辑器，Markdown 正文 + 双向链接 + 块引用
- 三层文件夹（项目/学科/主题）+ Vault 本地文件库导入导出
- AI 能力：续写、速览、文件夹整理、`正面 :: 背面` 行内成卡

### 2.3 卡片（间隔背诵）
- Anki 式卡片浏览器（8 列可排序、批量删除/重置、章节卡包）
- FSRS 间隔复习 + 掌握度 + 学习热力图（连续打卡）
- 四档评分显示真实下次间隔

### 2.4 刷题（题库练习）
- 四种模式：刷题 / 背诵 / 模考 / 错题本
- 答题卡（四态跳题）+ 计时 + 交卷报告（正确率/用时/知识点分布/逐题回顾）
- 错题本：按错次排序、重做、按章重试、转卡片

### 2.5 学习型 AI（差异化核心）
- **薄弱点出题**：按掌握度+错次 SQL 排序，不调模型
- **AI 讲解**：错题四段解析（考点/错因/步骤/关联），含 LaTeX
- **AI 组卷**：用我的资料生成模拟卷
- 问答：RAG（先查资料）→ 联网 → 学科知识，三阶段流式 + 来源芯片 + 沉淀为笔记/卡

### 2.6 视频解析
- 链接/上传视频 → 转写（字幕优先 / 必剪云端 / whisper 本地）
- 四模板笔记（摘要/大纲/问答/图文）+ 关键帧 + 时间戳跳转
- 整季批量导入（单批 50）+ 转写搜索 + Markdown 导出

### 2.7 平台能力
- 设置中心：AI 供应商/模型/转录器/平台 Cookie 全可配（密钥密文存储）
- 监控：任务队列、token 用量、成本、告警阈值
- 账号安全：HttpOnly Cookie、审计日志、数据导出/注销

## 三、与市面的差异（基于 34–37 号竞品调研）

### 3.1 我们比竞品强的

| 能力 | 竞品现状 | GFLC |
|---|---|---|
| **端到端闭环** | 墨墨只背词、粉笔只刷题、Obsidian 只记笔记 | 五段全通（唯一） |
| **资料转物料** | Anki/Quizlet 要用户手工造卡 | 自动解析 PDF/视频成卡/题 |
| **学习型 AI** | 竞品 AI 是「帮你写」 | 「按薄弱点出题 + 讲你的错题」 |
| **视频产物** | 会议型产品（听悟/妙记）只转写+摘要 | 四模板 + 关键帧 + 时间戳 + 批量 |

### 3.2 我们还差的（待补全，见 §五）

| 差距 | 竞品 | 我们现状 |
|---|---|---|
| 单词/词库 | 墨墨/不背/欧路有词书 | ❌ 无词实体（战略放弃） |
| 题库规模 | 粉笔/猿题库百万级 | 靠用户自己资料（定位使然） |
| 遗忘曲线 | Anki/墨墨 | 有热力图，缺遗忘曲线图 |
| 多视图笔记 | Notion 表格/看板/画廊 | 仅树+列表 |
| 图谱/反链聚合 | Obsidian 图谱视图 | 有反链列表，无图谱 |

## 五、待补全差异清单（按优先级）

## 六、一句话总结
