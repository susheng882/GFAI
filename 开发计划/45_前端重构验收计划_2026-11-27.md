# 45 · 前端重构验收计划（对标原型 v7l）

> 日期：2026-11-27　｜　重构源：`F:/output/gflc_prototype_v7l.html`（设计规范见 `_proto_v7l_设计规范.md`）
> 原则：**先验收标准后开发**。每项功能交付时必须通过对应验收项，否则不标记完成。

---

## 一、验收总则

1. **视觉对齐**：以原型截图为基准（`F:/output/v7l_probe/v_*.png`），主色 #0071E3、白底 #F5F5F7、卡片 12px 圆角、hover 抬升+蓝阴影。
2. **组件库纪律**：能用市面库的不用自写。自写新组件必须在本计划「允许自写清单」内，否则需说明理由。
3. **动效纪律**：仅 transform/opacity，150–280ms ease-out，受 `prefers-reduced-motion` 保护，键盘可达（focus-visible）。
4. **零回归**：现有 95 接口回归 + 24 单测每次交付都跑；前端 14 页路由不丢。

## 五、风险与对策

| 风险 | 对策 |
|---|---|
| Tailwind preflight 与 antd 样式冲突 | 不引入 Tailwind，用 CSS 变量 + 精简 utility（原型 token 已够） |
| 大量页面并行改造互相冲突 | 每 Agent 只改自己负责的页面文件，AppShell/theme 由 agent-design 独占 |
| FullCalendar 体积大 | 仅 PlansPage 动态 import |
| 图表换库数据对不上 | 换库前后截图对比 + 接口数据一致断言 |
