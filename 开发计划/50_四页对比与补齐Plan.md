## 一、资料过多管理方案（回应你的第 1 点）

### 现状问题
资料列表只有「列表/网格」双态 + 默认倒序，资料一多（几十份）就找不到东西。

### 方案（对齐 v7l 原型的信息架构）

| 层级 | 原型做法 | 我们落地 |
|---|---|---|
| **文件夹分组** | 左树 228px：专业课/公共课/错题与复盘/速记卡/视频课程/复盘 6 组，组下有学科子级 | 后端 notes 已有 folder 三层结构（project/subject/topic），资料页接入同款左树 |
| **筛选工具条** | 类型筛选（全部/PDF/视频/笔记）+ 排序（最近/名称/大小）+ 搜索框 | 加 Segmented + Select 排序 + 搜索（下推 SQL） |
| **三态视图** | 列表（7 列）/ 网格（4 列卡）/ 分栏（目录+预览+属性） | 已有列表/网格，补「分栏」态 |
| **批量操作** | 勾选 → 底部深色操作条：加标签/移动/生成卡片 | 加多选 + selBar |
| **存储占用条** | 树底部显示存储占用 | 后端算文档总大小展示 |

### 执行优先级
1. 左文件夹树 + 拖拽归类（P0）
2. 筛选/排序/搜索（P0）
3. 分栏三态补齐（P1）
4. 批量操作条（P1）
