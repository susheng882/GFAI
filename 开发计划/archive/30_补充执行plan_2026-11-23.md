## 1. A 层：PDF 扫描解析质量与速度（核心）

**基线**：9.1MB / 13 页 → 96.14s，13/13 成功；目标 ≤90s（差 6.14s）。
**诊断依据**：`28_PDF扫描解析质量速度诊断.md`（✅已交付，含单页对照实验）。

### 1.1 根因（有实验数据）

- 96.14s 中约 **80% 是每页大模型推理 + 强制 JSON 输出**，20% 是串行渲染；base64/上传/本地解析可忽略。
- 单页对照实验（同页/同图/同模型）：**JSON 均值 19.76s vs 纯文本直出 15.41s**，公式标记 122≥118。
- 结论：**去 JSON 改纯文本直出是唯一三赢改动**——提速、公式不降、下游 `chunk_pages` 本就吃纯文本零改动。预计全量 **96.14s → 65–75s**。

### 1.2 质量优先的两个被低估风险（低成本高收益）

| 风险 | 现状 | 改法 | 成本/速度 |
|---|---|---|---|
| **A3 双栏无语义** | prompt 无分栏提示，题干/选项可能左右栏错配 | prompt 追加「分栏先左栏后右栏逐栏转录」 | 零成本 / 0s |
| **分块切断公式** | `chunking._pack` 按 300 字硬切 + 100 重叠，可能拆断 `$...$` | 把 `$...$` 作为不可拆单元；OCR 页临时放大 CHUNK_SIZE | 中成本 / 0s |

> 这两项优先级高于 JPEG/DPI 微调——用户眼里的"OCR 弄丢公式"很可能是分块的锅，不是 OCR 的锅。

### 1.3 推荐落地组合：三档预设（同一组旋钮，不引入第二套链路）

| 维度 | `balanced`（默认，推荐） | `quality` | `fast` |
|---|---|---|---|
| 输出格式 | **纯文本直出（无 JSON）** | 纯文本 | 纯文本 + 最短 prompt |
| DPI / JPEG | 140 / q72（不动） | 180–200 / q85 | 140 / q60 |
| prompt | 纯文本 + 分栏提示 + 表格/公式约束 | 追加 \frac/\sqrt/矩阵约束 + 分区转录 | 最短 |
| 并发 / max_tokens | 2 / 16000（不动） | 2 / 16000 | 2 / 12000 |
| 公式校验 / 失败页重试 / 页级缓存 | 开 / 1 次 / 开 | 开+可疑页二次调用 / 1 次 / 开 | 正则 / 0 次 / 开 |
| **预估耗时** | **65–75s** | 90–120s（质量换时间） | 55–65s |

**新增配置项**（沿用现有 4 项，不破坏部署）：`OCR_PROFILE=balanced`、`OCR_OUTPUT_FORMAT=plain`、`OCR_JPEG_QUALITY=72`、`OCR_COLUMN_AWARE=1`、`OCR_FORMULA_CHECK=1`、`OCR_CACHE_ENABLED=1`、`OCR_FAILED_PAGE_RETRY=1`、`OCR_OBSERVABILITY=1`。
**保持不变**：`OCR_MAX_CONCURRENCY=2`（账号硬约束）、`OCR_DPI=140`（110 已证伪）。

### 1.4 可观测性（先补，否则无法验证提速是否真实）

最小 4 项指标，均在 `ocr_pdf_to_pages` 内 append 到 `stats`，无 API 契约变更：
`ocr_json_retry_pages`（哪些页触发重试）、`ocr_page_chars`（每页字数）、`ocr_page_formula_count`（每页 `$` 数）、`ocr_page_seconds`（每页耗时）。

### 1.5 明确不做（已证伪 / ROI 低）

降 DPI 到 110（实测 121.86s 更慢）、并发提到 3（429 且排队 171s）、PNG/DeepSeek 通道（34.7s/页）、本地 PaddleOCR 部署、图像二值化降采样（省 <1s 但损质量）、economy 模型（未查证哪个支持视觉）。

### 1.6 验收门禁（A 层）

- **V-A1 速度**：同一 9.1MB / 13 页样本，全链路 **≤75s**（目标 90s，优化后应显著优于；跑 2 次取均值）。
- **V-A2 质量**：13 页全出 chunks；抽检 ≥3 页，公式 `$...$` 配平、双栏顺序、表格文字无系统性错配。
- **V-A3 分块完整性**：`ocr_formula_broken_chunks = 0`（分块后奇数 `$` 的块数为零）。
- **V-A4 可观测**：stats 含最小 4 项指标；`OCR_OUTPUT_FORMAT=json` 回归仍可用（兼容旧行为）。
- **V-A5 不回退**：`verify_all.py` 全绿、有文字层 PDF 解析耗时不劣化。
