## 1. 五维评审框架（判定标准 + 证据来源）

评审报告不写印象分，每个结论必须挂"命令 + 输出 + 文件行号"。

### D1 功能完整性
- 口径：产品报告 P2 主线 27 项 / V1.5 8 项 / 规划池 3 项
- 方法：接口清单 ↔ 路由实现 ↔ 前端页面三方对齐表；标「有接口无界面」「有界面无接口」「仅桩实现」
- 达标线：主线 27 项无缺口；桩实现全部明示

### D2 AI 解析速度（PDF / 试卷 / 视频）
- 指标：PDF 单份端到端 P95；视频「首帧可见（大纲先出）」与「全量完成」双指标；试卷跨页漏题率
- 方法：3 档样本（10 页 PDF / 60min 视频 / 2 页试卷）跑真实链路，记录阶段耗时分解（下载→转写→抽帧→OCR→生成）
- 达标线：PDF ≤60s P95；视频全量 ≤25min/60min；首屏可读 ≤10s

### D3 问答质量
- 指标：召回 / 命中 / MRR / 忠实度 / 拒答准确率 / 卡片可用率 + 端到端时延
- 方法：离线 24 问基线（已有）+ 在线 10 问抽测（真实 LLM）；上线前对比 bge 真权重 vs 哈希降级
- 达标线：忠实度 ≥85、拒答 ≥90、任一指标跨版下降 >3pp 即回滚（`eval_gate.py`）

### D4 性能与稳定性
- 指标：问答首字节 / 端到端、检索耗时（缓存命中）、20 并发队列行为、内存、任务失败率、看门狗误判
- 方法：`verify_all.py`（95 项断言）+ `deploy/stress_20.py` + 手工链路计时
- 达标线：关键接口 P95 ≤3s；95/95；20 并发零 OOM、零静默失败

### D5 UX / UI
- 指标：首屏 ≤2s、三档视口（1440/768/430）零横向滚动、暗色可读、键盘可达、空/错/载三态齐备、信息层级（hero:正文 ≥2.0 倍）
- 方法：Playwright 全页截图 + 逐页清单核对 + 与 `gflc-design` 设计系统自查 9 条
- 达标线：P0/P1 缺陷清零

## 3. UI 改造方案（对标参考图）

参考图特征：暖砂米底 + 玫瑰/珊瑚强调 + 浮层外壳（外层暖底、内层圆角白壳、极细边）+ 图标窄栏 + 二级导航面板 + 大圆角卡片 + 超大 hero 数字 + 单位胶囊 + 极简柱/面积图 + 协作者头像行。

### 3.1 迁移决策（复制"决策"，不复制像素）

| 参考图做法 | 采用 | 理由 / 落到本项目 |
|---|---|---|
| 暖砂底 `#efe6e2` 系 + 内层近白卡面 | ✅ | 与现有"纸墨暖白"同源，只需把底再降一档暖度，形成"浮起"层次 |
| 玫瑰/珊瑚作为**唯一数据强调色** | ✅ | 现在唯一强调色是墨蓝，用于交互；玫瑰专门给"今日/到期/涨跌"类数据，语义分离 |
| 浮层外壳（外底 + 圆角内壳 + 1px 细边） | ✅ | 替换现在"整屏平铺 + 卡片贴边"，是本次视觉升级的最大杠杆 |
| 图标窄栏 58px + 二级导航面板 200px | ✅ | 现在 240px 单列侧栏占宽；改双栏后内容区可到 1440 不挤 |
| 卡片圆角 14–18px + 柔和投影，去硬边框 | ✅（圆角取上限 16） | 现有 `--radius: 8px` 偏"办公软件"；提到 16 更接近参考图气质 |
| 大号 hero 数字 + 小号单位胶囊 + 百分比徽章 | ✅ | 仪表盘已有 hero，补胶囊/徽章语法 |
| 极简柱图 + 面积折线（单色系、无网格框） | ✅ | 现有图表已朝这方向，继续收紧 |
| 头像/协作行 | ⚠️ 部分 | 单人产品不做"协作"，改为"资料/任务来源"标识行 |
| 大面积粉色铺底、装饰渐变、彩色标签堆叠 | ❌ | 与"克制、可长时间学习"冲突，且参考图本身也是低饱和为主 |
| 卡片可拖拽自由布局 | ❌ | 学习场景不是 BI，固定栅格更好扫读 |

### 3.2 Token 变更（`gflc/web/src/theme.css`）

| 变量 | v3 现值 | v4 提案 | 说明 |
|---|---|---|---|
| `--background` | `#f7f4ee` | `#efe8e1` | 外层底，降一档暖度 |
| `--card` | `#fdfbf7` | `#fffdfa` | 浮起后更白，靠"底深卡浅"造层次 |
| `--radius` | `8px` | `16px`（xs/sm/md/lg/xl 派生不变） | 单源派生机制保留 |
| `--primary` | `#1f4d6b` | 保持墨蓝 | 交互色不动，避免全站返工 |
| `--rose`（新增） | — | `#d4707a` / soft `#f8e6e6` | 只给数据强调，禁止用于按钮 |
| `--shell`（新增） | — | `#fffdfa` + `1px solid rgba(31,27,22,.06)` | 浮层内壳 |
| `--shadow-card` | — | `0 1px 2px rgba(31,27,22,.04), 0 8px 24px -12px rgba(31,27,22,.10)` | 替代硬边框 |

约束：新增强调色**必须有且仅有**一处语义（数据强调），并在设计系统里写死"禁止用于交互态"。

### 3.3 落地顺序

- P0 外壳 + 仪表盘（导航双栏、hero、指标带、队列、最近资料）
- P1 资料库 / 问答（AI 白盒过程行与玫瑰强调的兼容）
- P2 笔记 / 卡包 / 学习 / 复习 / 计划 / 任务 / 视频 / 登录

U1 三档视口零横向滚动；U2 暗色对比度 ≥4.5:1（正文）；U3 首屏 ≤2s；U4 每页空/错/载三态；U5 hero:正文 ≥2.0 倍；U6 玫瑰色零交互态误用；U7 全部键盘可达、focus 可见；U8 无 `transition: all`；U9 圆角/间距全走 token；U10 截图逐页归档 `gflc/docs/screenshots/v4/`。
