## 一、结论先行

本机和"能上线"是两套配置：本机跑 `DEV_MODE=true + SQLite + 本地磁盘`，生产模板是 `PostgreSQL(pgvector) + MinIO + Redis`。本次已经完成两件事：**打包链路修复**和**S1–S6 安全加固**，并做了全量回归。你现在缺的是**买域名 + 买服务器 + 备案**，以及启动 Docker Desktop 跑一次构建。

### 1.1 打包链路已修复（本次完成）

| 问题 | 后果 | 修复 |
|---|---|---|
| `nginx.conf` 的 `/` 直接返回一行文字 | 前端完全打不开 | 改代理到 app 的 StaticFiles；流式接口单独长超时、关缓冲 |

### 阶段 B — 国内服务器 + 域名 + 备案（关键路径）

**今天就要启动的事（备案是长周期，其他工作可并行）：**

1. **买域名**：阿里云/腾讯云均可，`.com` 首年约 ¥60–100，`.cn` 约 ¥30–50。买完立刻做**实名认证**（备案前置条件，通常 1–3 天）。
2. **买国内云服务器**：阿里云 ECS / 腾讯云 CVM，2 核 4G 起步（faster-whisper CPU 转写吃资源），系统选 Ubuntu 22.04。**买满 3 个月**的机器备案更顺利（部分厂商要求）。
3. **提交 ICP 备案**：在云服务器厂商的备案系统提交，免费。准备：域名证书、身份证、人脸核验、服务器 IP。**周期 20–60 天**。备案期间先用 IP + 自签证书在内网验证，不对外。
4. **安全组**：只开放 `80 / 443 / 9000`，其余全关。9000 是浏览器预签名直传 MinIO 必需。

**备案通过后配置 HTTPS**（约 10 分钟）：

```bash
# 用 certbot 或云厂商免费证书，放到 deploy/certs/fullchain.pem 与 privkey.pem
cp deploy/nginx-ssl.conf.example deploy/nginx-ssl.conf
# 把里面的 your.domain.com 换成你的域名
docker compose -f docker-compose.yml -f docker-compose.ssl.yml up -d
```

覆盖层会自动把 `COOKIE_SECURE=true`、CORS 白名单切到你的域名。

**验收门禁**：`https://域名/health` 可访问；浏览器锁标志；Cookie 带 `Secure`；`http://` 自动 301 到 `https://`；备案号已在工信部系统可查。
