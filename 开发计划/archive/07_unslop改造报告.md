## 一、方向（五句话）

## 三、九道 pass 做了什么

### Pass 1 · 间距
- 全部尺寸回到 **4px 栅格**：卡片内边距统一 20（紧版 16），页面内边距 24/32，栅格 gap 统一 16
- 侧栏 **236 → 240**，导航行高 34、组间距 12、组标签 8 上 4 下
- 学习页三栏 `align-items:start → stretch`，三栏**底部齐平**
- 内容区 `max-width:1080 → 1400`，回到真实应用比例（不再是居中窄栏）

### Pass 2 · 色彩
- 新建**暖纸中性阶**：`#f7f4ee` 底 / `#fdfbf7` 卡 / `#efe9df` 抬升 / `#1f1b16` 正文 / `#4a4238` 次要 / `#7b7266` 元信息
- 强调色收敛成**一个墨蓝 `#1f4d6b`**，只用于：选中指示条、主图线、时间戳、链接
- **主按钮改墨色**（`#26211b` + 纸白），不再是蓝按钮 —— 蓝色从 chrome 退出
- 边框统一发丝线 `rgba(31,27,22,.10)`；去掉蓝色系内阴影与三套阴影，只留两级
- 深色重算：`#0f0e0c` 底 / `#1c1915` 卡 / `#0a0908` 侧栏，发丝线 13%（**三层能分开**）
- 语义色压饱和：success `#2f6b4f`、warning `#8a6220`、destructive `#a8322c`

### Pass 3 · 图标
- 补齐图标集到 **16 个**内联 SVG，统一 **24 网格 / 1.5 stroke / 圆角端点 / currentColor**
- `📎` → `paperclip`（**修掉实拍里的方块乱码**）
- `⠿` 拖拽点阵**删除**（拖动靠 cursor 与落位反馈）
- `‹ ⎋ ▶ ✦ ☰ ☀ ☾` → `collapseLeft / logout / chevron / spark / menu / sun / moon`
- 图标盒统一 18px，与文字间距 10px，一列对齐

### Pass 4 · 文案
- 页头副标题从操作说明改成**页面定位**：`双击卡片改数据…` → `按主题生成的进度概览`
- `三种笔记模板` → `上传或贴链接，自动生成四种笔记`
- 删掉「公式用 LaTeX 渲染；回答在下方滚动，输入框固定」
- 删掉每张卡的「真实数据：」前缀（保留后半句信息）
- 任务错误**脱敏**：绝对路径 → `（本地临时文件）`，超 70 字截断
- 时间 `11-21T12:15` → `11-21 12:15`
- 「开始提问吧」→「开始提问」（去掉招呼腔）

### Pass 5 · 字体
- 字重收敛到 **400 / 500 两档**，`600` 从 33 处降到 **0**，`700` 降到 0
- 层级改由**字号 + 颜色**承担：页面标题 17/500、卡片标题 12/400、统计数字 30/500
- 数字启用 `tabular-nums`；时间戳、计数、代码走等宽 `--mono`
- 去掉小字负字距与 `text-transform:uppercase` 标签

### Pass 6 · 布局
- **问答页**：空状态垂直居中，**272px 死白带消失**；输入区固定底部不变
- **视频页**：上传区改成「虚线上传框 + 或 + 链接输入」，一行水平对齐，不再是孤零零的按钮
- **笔记页**：四栏 228 / 248 / 1fr / 300，编辑器拿到 ~460px；非手写笔记**默认进预览**
- **仪表盘**：图表卡最小 span 6（原来被压到 179px，8 个时间标签挤成一团）；示例布局重排为 3 行有节奏的 3/6/3 · 6/3 · 5/3

### Pass 7 · 细节
- 半径阶梯：控件 8 / 卡片 12 / 面板 14（原来统一 19px，全是"大圆角"）
- 学习页统计**去掉卡中卡**：4 个小卡改成带发丝线的数据条
- 表格：表头 11.5/400，行高 44，hover 用暖 accent，首列 500
- 徽章 20px 高、4px 圆角，语义色只表意
- 文档页 36 个等价按钮 → **解析（描边）/ 生成卡片·改名（文字）/ 删除（文字，hover 变红）**
- 任务页失败行不再显示进度条，改为「未完成」
- 焦点环 3px → 2px / 12%，输入框不再有霓虹双描边

### Pass 8 · 视觉
- 折线图**重画**：Catmull-Rom 平滑曲线、3 条发丝网格、5% 面积、`vector-effect` 保证线宽不随拉伸变形、等宽标签
- 柱状图：只有**最高柱**用强调色，其余走中性；0 值画成 2px 基线刻度（不再像渲染失败）
- 环形图：中性轨道 + 单一强调环 + 等宽数字
- **荧光笔签名**落地：`今日推荐` 章节名、`待复习 N 张`、`待复习卡片 27 张`

### Pass 9 · 动效
- `transition:all` **全部删除**，只过渡 color / background / border / opacity / transform
- 统一一条曲线 `cubic-bezier(.22,1,.36,1)`，三档时长 140 / 180 / 320ms
- 删掉卡片入场动画（原来每张卡各飞一次），只保留页面级 320ms 淡入上移 6px
- 删掉卡片 hover 上浮与彩色阴影，改为边框加深 + 2px 中性阴影
- 尊重 `prefers-reduced-motion`

## 六、这次没做（明确说明）

1. **换字体族**：中文 UI 走系统字体（PingFang / 微软雅黑），没有自托管中文字体（体积 2–5MB，且本机离线环境）。层级改用字号与颜色解决。
2. **生成 unslop 变化视频**：本轮你选的是"深色同步审计"，未生成 story 视频。需要时可再跑 `story.mjs`。
3. **视频时间轴跳转播放位置**：需要播放器联动，属功能而非视觉。
4. **B站/抖音内嵌播放**：需代理，未做。
5. **截图里的历史数据**：`tts_zh.wav`、`链接视频` 等测试条目仍在演示库里。
