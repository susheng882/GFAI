## 4. OCR 质量与速度 · 本轮诚实结论

### 4.1 质量（确定性，不受网络影响）

| 指标 | 结果 |
|---|---|
| 页成功率 | **13/13**（全部 4 次实测） |
| 公式标记总数 | 886–902（与优化前同量级或更高） |
| 公式配平可疑页 | **0** |
| JSON 重试页 | `plain` 模式 **0 页**；`json` 模式 **1–3 页** |

### 4.2 速度（受方舟 API 负载影响极大，必须如实呈现）

同一时段交替对照（排除时间漂移）：

| 模式 | 第 1 次 | 第 2 次 | 均值 | 重试页 |
|---|---|---|---|---|
| `json`（旧行为） | 135.02s | 118.79s | **126.90s** | [6,13] / [6] |
| `plain`（新行为） | 88.79s | 116.63s | **102.71s** | 无 |

**相对收益确定：plain 比 json 快约 19%，且零重试**（重试会带来语义漂移风险）。

**绝对值波动区间**（plain 模式多次实测）：**66.51s – 131.10s，中位数 85.28s**。
- 低峰期（早前实测）：65.80 / 67.63 / 66.51s → 达到 75s 目标
- 高峰期（本次实测）：85.28 / 116.63 / 131.10s → 未达 75s

**结论**：代码层优化（去 JSON、并行渲染、分栏 prompt、公式原子化）**真实有效且质量无损**；但 75s 绝对目标在方舟晚高峰不可达，瓶颈是模型排队而非本系统。**不宣称稳定达标，只宣称相对提速 19% + 质量零损失**。
