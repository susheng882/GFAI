# 第三轮优化验收标准（UI 体验 / AI 质量 / 测试与成本）

> 制定时间：2026-11-21 19:30
> 依据：用户第三轮反馈（视频页体验、仪表盘图表不可改、笔记预览与整理、问答质量差、视频笔记不能用、关键帧图文、文档类视频信息提取、测试维度与 token 管控）
> 自动化：`gflc/backend/scripts/verify_all.py`（接口）+ `scripts/quality_eval.py`（质量）
> 判定原则：**每条都要能拿数据说话**；未达标的写"未通过"，不写"基本可用"

---

## 一、视觉与交互（UI）

| # | 需求 | 可测验收标准 | 判定方法 |
|---|---|---|---|
| **U1** | 视频页：左侧视频 + 下方关键帧 | ① 左侧有播放器区域（有视频源可播放、无源显示占位说明）② 播放器下方是关键帧横向缩略图条，每张带时间戳 ③ 文档类帧有「文档」标记 | 截图 + 页面元素计数（`.vthumb` ≥ 1） |
| **U2** | 视频页：右侧大纲树状图（仿百度网盘） | 大纲笔记以**缩进树 + 连接线**呈现，一级/二级/三级有层级区分；节点可折叠；不是一段平铺文字 | 截图 + DOM 含 `.vtree li` ≥ 3 层 |
| **U3** | 仪表盘：图表数据可双击修改 | 双击柱状/折线卡片 → 背面出现**数据行编辑**（标签+数值）；可增行、删行；保存后图表按新数据重绘；刷新后保持 | 手工：改 3 个数据点 → 保存 → 图表变化 → 刷新仍为改后值 |
| **U4** | 仪表盘：交互不变差 | 双击翻转、右下角缩放、拖拽换位 三者可同时工作，互不冲突；无编辑按钮 | 连续操作 5 次无异常 |
| **U5** | 笔记：卡片预览 | 列表项显示 标题 + 摘要两行 + 来源徽章 + 字数 + 所属末级文件夹 | 截图 |
| **U6** | 笔记：AI 整理 | 点文件夹栏「✦」→ 10–25s 内返回：总结、建议新建的归类文件夹（含应移入的笔记）、疑似重复可合并、缺失知识点；**不自动改动**，用户点「建文件夹并移入」才执行 | 手工 + 接口返回结构校验 |
| **U7** | 过渡体验 | 页面切换有淡入位移（~0.3s）；卡片翻转 3D（~0.58s）；关键帧图片懒加载；无布局跳动 | 录屏/截图对比 |

## 二、AI 质量

| # | 需求 | 可测验收标准 | 判定方法 |
|---|---|---|---|
| **Q1** | 问答不得被错误实体带偏 | 问「泰勒公式有什么」时，回答中**不得出现**：歌手 / 斯威夫特 / Swift / 音乐 / 专辑 / 娱乐 | 关键词黑名单检测（脚本自动） |
| **Q2** | 问答详尽度 | 数学/概念类问题回答 ≥ **250 字**；含结构（小标题或列表）与公式（LaTeX `$...$`） | 字数 + 结构标记检测 |
| **Q3** | 检索相关性（重排生效） | 10 题评测集（6 相关 + 2 诱饵 + 2 跨领域同名词），**Top1 命中率 ≥ 80%**，诱饵题不得硬答 | `quality_eval.py` 报告 |
| **Q4** | 引用规范 | `mode=knowledge` 必含 `[1]` 编号；`mode=web` 必含 URL；`mode=model` 必含「模型知识」提示 | 脚本正则 |
| **Q5** | 视频笔记能用 | 摘要模式：summary ≥ 250 字、points ≥ **8 条**且每条 ≥ 15 字；大纲模式：≥ 3 个一级标题；问答模式：≥ **8 组** | 结构化断言 |
| **Q6** | 关键帧图文笔记 | 视频源能抽出 ≥ 6 帧（不足则等间隔补齐）；文档帧能 OCR 出文字；生成「图文」笔记（kind=frames）含 summary + ≥ 3 个 section | 接口返回断言 |
| **Q7** | 文档类视频信息提取 | 上传含 PPT/讲义的视频，关键帧 OCR 能还原图中**标题、列表、公式**，并进入图文笔记 | 人工抽检 2 个视频 |
| **Q8** | 转写质量 | 中文音频输出**简体**；明显错字被摘要模型标注纠正 | 抽检输出 |

## 三、测试维度与成本

| # | 需求 | 可测验收标准 | 判定方法 |
|---|---|---|---|
| **T1** | 接口测试覆盖面 | 从 84 项扩到 **≥ 95 项**，覆盖笔记整理、视频关键帧、问答 mode、任务重试、token 超限 | `verify_all.py` 通过率 100% |
| **T2** | 多维度质量评测 | 五个维度打分：正确性/完整性/引用规范/时延/成本；输出总分（满分 10），**≥ 7.5 视为达标** | `quality_eval.py` |
| **T3** | Token 管控 | 单用户日 token 上限（默认 300k）、日成本上限（默认 ¥2）、单任务上限（60k）；超限返回 `QUOTA-001` 且提示可读 | 调小阈值实测拦截 |
| **T4** | 质量与成本平衡 | 单次问答 ≤ **2 次 LLM 调用**；评测集总花费 ≤ **¥0.10** | 读 `cost_ledger` |
| **T5** | 后台任务健壮性 | 超时（600s 无进度）自动失败；重启后 running 标中断、pending 重入队；失败可 retry | `/tasks/health` + 实测 |

## 四、本轮不做（明确排除，避免验收争议）

1. **B站/抖音视频原画播放**：跨域与防盗链限制，未做代理播放；只做关键帧与转写。
2. **关键帧点击跳转到播放位置**：需视频源可 seek，音频/B站链接不适用（已实现"有源则 seek"）。
3. **笔记局部划词改写**：本轮只做整篇 append/replace/prepend。
4. **题目识别 22 题全量**：仍为 16/22，跨页与纯图解答题未补。
5. **Docker/CI/压测**：仍未做。

## 五、验收流程

```bash
# 1. 接口全量
cd gflc/backend && python scripts/verify_all.py

# 2. 质量评测（需真实 Key）
cd gflc/backend && python scripts/quality_eval.py

# 3. 人工截图清单
仪表盘翻转改图表数据 / 视频页左视频右树状大纲 / 笔记卡片预览 / AI整理弹层
```

通过标准：T1 100% 通过 + T2 ≥ 7.5 + Q1 零命中黑名单 + U3/U6 手工通过。
