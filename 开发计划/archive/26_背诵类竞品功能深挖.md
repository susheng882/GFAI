## 7. 布局骨架对比（区块层级）

> 只描述「区块层级」与「什么时候出现什么」，不涉及像素、配色与图标。

### 7.1 背诵页（GFLC `StudyPage.jsx` 背诵态）

- **竞品骨架**：Quizlet「集合内多模式标签 → 居中大卡 → 点卡翻面 → 前后箭头」；墨墨「单卡聚焦 + 底部四档反馈」。
- **GFLC 现状**：`Segmented(刷题/背诵/错题本)` → 控制条(题量/导入题库) → 背诵态「第 n/N · 点击卡片翻面」→ 单卡 → 「上一张/下一张」。**缺评分反馈，无今日队列条**。
- **建议骨架（自上而下）**：
  1. 模式切换（一级导航，保留）
  2. **今日队列条**（新增）：「今日 W 项 = 复习 Y + 新学 Z」，数字用 `.mono`，不用荧光笔
  3. 卡包选择 chips（未进入单卡时显示；进入后隐藏）
  4. **全屏单卡**（进入后唯一主数据层）：正面 → 点卡/按钮翻面 → 答案
  5. **翻面后反馈条**（新增）：`记住了`（实心主按钮）+ `再练一次`（outline）；二元优先，四档作远期升级
  6. 翻页控制（上一张/下一张，次级）
- **空态**：未选卡包 → 「选择卡包开始背诵」+ 卡包 chips；题库空 → 主 CTA「导入题库」跳资料页。

### 7.2 卡片浏览器（GFLC `DecksPage.jsx` 卡片浏览）

- **竞品骨架**：Anki 三段式 = 左侧筛选树 + 右上表格 + 右下编辑区，三块可伸缩。
- **GFLC 现状**：`Segmented(章节卡包/卡片浏览)` → 筛选条(关键词/卡包/熟练度) + 批量条 → 表格 → 编辑 Modal（浮层，非右下常驻）。
- **建议骨架（自上而下）**：
  1. 视图切换（章节卡包 / 卡片浏览）
  2. 卡包概览网格（仅在「章节卡包」视图；点分册展开卡片列表）
  3. **筛选条**（吸附在表格上方）：关键词 / 卡包 / 熟练度 / 到期状态（新增）+ 「重置筛选」
  4. **表格**（主数据层）：卡片内容 / 卡包 / 熟练度 / **下次复习** / **复习次数** / 操作；列头可排序；选中 N 行时上方浮现批量条（删除 / 重置进度）
  5. 编辑 Modal（浮层，保持）
- **与 Anki 的差异取舍**：不强做三块拖拽分隔（GFLC 硬规则）；编辑保留 Modal，不占常驻行数。

### 7.3 复习会话页（GFLC `ReviewPage.jsx`）

- **竞品骨架**：Anki「deck overview 三色计数 → 全屏单卡 → 四档（带间隔）→ 剩余数」；墨墨「单卡 + 底部四档改排期」。
- **GFLC 现状**：日目标卡（目标/进度条/剩余）→ 当前卡片元信息 → 单卡（显示答案）→ 四档评分（hint 占位）→ 底部「剩余 N 张」Tag。
- **建议骨架（自上而下）**：
  1. **今日目标条**：`今日目标 done/goal` + 目标 InputNumber + 进度条 + `剩余 N 张`（荧光笔 `.hl` 只标剩余数，全页唯一）
  2. 当前卡片元信息（第几页 · 已复习几次）
  3. **单卡**：问题 → 点「显示答案」后出答案（Markdown）；未翻面前**只有这一个实心主按钮**
  4. **四档评分条**（翻面后出现）：`忘记 / 费力 / 记住 / 秒懂` → 1–4；`记住` 为实心，其余 outline；**每档下方显示下次间隔预期**（后端未返回时显示占位语义并标注待接口确认，不编造天数）
  5. 会话内操作（次级）：`标记掌握 / 延后 / 重置`（远期，对应 Top10 第 4/7 项）
  6. 完成一轮：`message.success` + 一行「今天已完成，明天再来」
- **空态**：「今天没有到期的卡片」+ 可点「去背诵」跳 `/study`，形成回流。

### 9.1 改了哪些文件

- 仅新建本文 `开发计划/26_背诵类竞品功能深挖.md`。未修改任何其他文件，未运行服务，未改 `.env`，未 git 提交。

### 9.2 核心结论（5 条以内）

1. **最高价值的一条是「评分显示下次间隔」与「今日队列合并」**：前者官方手册明确、我们缺具体值且需后端预览接口；后者可纯前端聚合，本期就能做。
2. **背诵页目前是「翻页器」不是「复习器」**：翻面后无评分闭环，接入现有 `POST /review/{id}` 即可升级，成本最低、闭环收益最大。
3. **「永久掌握」档是四档模型的关键缺口**：墨墨「熟知」证明用户需要「不再复习」的显式出口，GFLC 需新增字段或约定特殊 rating。
4. **卡片浏览器的差距在「排期维度」而非表格本身**：已有筛选/批量，缺列排序、Interval/Lapses 列、挂起/标记与设到期。
5. **Anki 的模板/多字段与扇贝的语境串学属于 P2**：需数据模型改造或内容生成链路，不建议与本期 P0/P1 混排。
