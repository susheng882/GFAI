## 一、项目全景（一眼看清现在是什么）

**定位**：考研/考证场景的 AI 学习伴侣 —— 资料进来，卡片/题库/笔记出去，配复习排期与问答。

**技术栈**

| 层 | 选型 | 说明 |
|---|---|---|
| 后端 | Python 3.11 + FastAPI + SQLAlchemy 2 + Alembic | 单进程 + 内置单线程 worker 队列 |
| 数据库 | SQLite（本地）/ PostgreSQL（生产预留） | 16 张表，迁移到 `0007` |
| 模型 | DeepSeek V4.1-Flash（light/mid）+ V4-Pro（strong） | 支持视觉（读题/读帧），**无 embedding** |
| 检索 | jieba + BM25Plus + LLM 重排 | 无向量库 |
| 前端 | 原生单页（无构建） + KaTeX | 2010 行，9 个页面 |
| 媒体 | ffmpeg 8.0 + faster-whisper + opencc | 抽音频/抽帧/转写/繁转简 |

**代码规模**：后端 51 个 Python 文件 / ~4600 行；前端 1 个 HTML / 2010 行。

**数据模型（16 表）**
`users` `documents` `chunks` `cards` `card_decks` `questions` `question_banks` `attempts`
`plans` `plan_tasks` `notes` `note_folders` `dashboard_layouts` `tasks` `cost_ledger` `alembic_version`

**页面（9 个）**
仪表盘 · 笔记 · 文档 · 卡包 · 学习（刷题+背诵） · 复习 · 问答 · 视频 · 任务

### 5.3 踩过的坑（别重复踩）

1. **BM25Plus 的 IDF 恒正** → "有分数"不代表"有依据"，必须加**语义重排**或覆盖率判定。
2. **同名不同领域的词**（泰勒公式 vs 泰勒·斯威夫特）→ 必须做**领域消歧**（查询改写 + 重排）。
3. **`chapter/section/no` 可为 NULL** → Pydantic schema 要写 `str | None`，否则历史数据 500。
4. **12 栅格 span 组合必然留白** → 用「按行分组 + flex 比例」。
5. **窄容器里用 `<table>`** → 中文会被压成竖排，改 flex 行。
6. **JS 单引号字符串不能跨行** → 多行 HTML 必须反引号模板串。
7. **whisper 中文偏繁体** → `initial_prompt` 引导 + opencc 兜底。
8. **同步重活阻塞事件循环** → 所有 >1s 操作必须走 worker。
9. **前端重复 id**（`theme` 被按钮和输入框共用）→ 改 id 命名。
10. **改完 model 忘跑迁移** → 报 `no such column`。

### 5.4 多 Agent 协作经验

- **文件白名单**是唯一有效防冲突手段；每次派活都写明"只能改这些文件，禁止改哪些"。
- 契约（models/schemas/prompts）必须**主控先定**，agent 只读不改。
- 每个 agent 都要**真跑接口**，不接受"编译通过"当验收。
- agent 报告里要求贴**实际数字**（多少个、多少秒、多少字），否则容易是编的。

## 七、本阶段结论

- **可演示**：9 个页面、95+ 接口、四条主路径（资料→卡片→复习→问答）均可实跑。
- **可用性**：仪表盘/笔记/学习三页达到"能日常用"的水平；视频笔记可用但依赖源质量。
- **未达上线**：缺 CI、压测、备份演练、合规审查；单机 SQLite 不具备并发能力。
- **最大的质量短板**：转写精度与试卷识别完整度 —— 这两项直接决定"内容是否可信"，建议优先投入。
