## 二、验收方法

### 2.1 自动化（可复跑）
```bash
cd gflc/backend && python scripts/verify_all.py
```
输出 35+ 项通过/失败，退出码非 0 表示有失败。

### 2.2 手工验收清单（每批次交付时执行）
1. 上传《凯哥数学一模拟卷》→ 题库出现 16 题、3 章节、公式可读
2. 上传 PDF → 右下角进度条推进 → 任务页出现记录
3. 点章节 → 题目正确、选项完整
4. 仪表盘输入主题 → 生成 → 拖拽 → 刷新保持
5. 问答带上资料提问 → 有引用；不带资料提问 → 有回答且标注来源

## 四、已知限制（需说明，避免验收争议）

1. **公式渲染**：题库页用 KaTeX 渲染；若 CDN 不可用则回退为 LaTeX 源码（仍可读）。
2. **题目完整性**：当前识别 16/22 题，缺 6 题（含跨页/纯图解答题）。属视觉识别边界，B2 会加"补漏识别"。
3. **答案**：试卷未印答案时留空，不编造；可后续上传答案卷匹配。
4. **抖音**：需用户提供 `cookies.txt`；YouTube/快手受本机网络限制。
5. **向量检索**：DeepSeek 无 embedding，当前为 BM25 关键词召回。
