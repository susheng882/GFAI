## 三、本轮优化总览（11-27 ~ 11-28）

### 设计系统
- Apple 白（#F5F5F7 底 / #0071E3 主色 / 16px 圆角 / 毛玻璃侧栏）
- 动效：150-260ms ease-out、卡片入场 fade-up、reduced-motion 保护

### 布局占满（7 页扩充）
docs 653→1081 / review 605→826 / qa 725→827 / settings 555→978 / banks 682→902 / study 521→1125 / notes 638→1134（px，内容高）

### 交互增强
- 侧栏宽度拖拽 180-320px（记忆）+ 228/64 收起切换
- 视频右栏笔记区拖拽 280-520px（记忆）
- 分页：docs/banks 列表 + 筛选重置页码
- 空态：虚线框 + 图标 + 主副文案 + 动作按钮

### 底部留白统一
- 内容 wrapper 统一 `pb-6`（24px）底部留白
- 一屏内页面高度 792-844px 自然分布，超出页面正常滚动
