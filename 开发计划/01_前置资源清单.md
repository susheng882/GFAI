# GFLC 前置资源清单

> 结论：**开发阶段本机环境已全部具备，唯一需要你提供的是 DeepSeek API Key（没有也能先跑 Mock 演示）。**

## 一、必需（本机已具备 ✅）

| 项 | 版本要求 | 本机实况 |
|---|---|---|
| Docker + Compose | 20+ / v2 | ✅ 27.4.0 + v2.31 |
| Python | 3.11+ | ✅ 3.11.7 |
| Node.js | 20+ | ✅ 22.22.2 |
| pip | — | ✅ 23.3.1 |
| Git | — | ✅（用于 clone BiliNote，P3 阶段需要） |

## 二、需要你提供（1 项）

| 项 | 用途 | 没有会怎样 | 怎么拿 |
|---|---|---|---|
| **DeepSeek API Key** | 卡片生成、题目解析、问答 | 自动走 **Mock 模式**（规则生成，能跑通流程但质量是占位的） | platform.deepseek.com → API Keys → 创建；充值 ¥10 起 |

> Mock 模式下整条流程（上传→解析→卡片→复习）都能跑，只是卡片内容由规则抽取、不是大模型生成。填了 Key 重起服务即切真实模型。

## 三、可选（答辩/上线前）

| 项 | 规格 | 费用 | 何时需要 |
|---|---|---|---|
| 云服务器 | 2C4G5M 轻量（腾讯云） | 活动价 ¥188/年 | 需要公网演示/上线时 |
| 域名 | 常规后缀 | ¥60/年 | 同上 |
| ICP 备案 | 自行办理 | ¥0 | 上线前，周期 2–3 周，建议提前 |
| 本地 GPU | 可选 | — | 视频转写加速；无 GPU 用 CPU int8 也能跑 |

## 四、自动准备（代码已处理，不用你操心）

- 数据库表：启动时 `alembic upgrade head` 自动建
- MinIO bucket：启动时自动创建
- 依赖包：`docker compose build` 自动装；本地跑用 `pip install -r requirements.txt`
- 前端：单页由后端静态托管，**不需要 npm build**

## 五、一句话启动

```bash
cd gflc/deploy
cp .env.example .env        # 想用真模型就填 LLM_API_KEY；不填走 Mock
docker compose up -d --build
# 打开 http://localhost
```
