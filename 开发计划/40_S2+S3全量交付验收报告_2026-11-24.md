### 2.2 掌握度统一（P-3 修复，零迁移）

**决策**：不做破坏性数据迁移（61 卡 + 24 题真实数据，风险 > 收益），改为**只读聚合画像 + 两步确认的安全对齐**。

| 接口 | 行为 |
|---|---|
| `GET /api/mastery/insight` | overall + by_document + by_chapter + divergence；口径 `score = 卡 0.5 / 题 0.5 加权，单侧无观测以另一侧为准`；一次调用 16 条 SQL（4 条 GROUP BY） |
| `GET /api/mastery/reconcile/preview` | **只读**，返回将对齐的卡片清单与前后值（实测前后 DB 快照 `before == after`） |
| `POST /api/mastery/reconcile` | 执行对齐，**只改 mastery**，`due_at/reps/lapses/fsrs_state` 全部不变（逐行比对确认） |

**实测**：`score 0.005 not_started`，cards 26 / questions 24，by_document 3 / by_chapter 9。
**前端**：资料详情掌握度块内增加「按章节分布」（最多 8 条条形）+「差异 N 处」链接 → 抽屉里 preview → 确认才写库。

**已知限制**：卡片到章节的归属依赖 PDF 大纲生成的章节卡包；未挂章节包的旧卡只计入总画像，不进入章节分布（零迁移的必然代价）。

## 三、S3 学习型 AI（P-4 差异化）

| 接口 | 实现 | 实测 |
|---|---|---|
| `POST /ai/weak-quiz` | **零模型调用**；SQL 排序「未做过置后 → mastery ASC → 错次 DESC」；连对 3 次的题用相关子查询过滤 | 3 题，reason「还没做过 · 掌握度 0.00」可解释 |
| `POST /ai/explain` | mid 档四段（考点/错因/步骤/关联），输入含题干+选项+答案+最近 3 次作答 | **4.3s**：准确识别「等价无穷小 + 泰勒展开」，指出真实错因（忽略高阶项 / 把极限为 0 误当分子为 0），4 步含 LaTeX 推导，4 个关联知识点 |
| `POST /ai/mock-paper` | 资料前 30 段 → 出卷 → 落库 QuestionBank + Questions | **7.2s / 5 题 / 题库 59**，章节「AI 模拟卷」可直接在刷题页练习 |

**为什么这是差异化**：竞品（墨墨/粉笔/Anki）都没有「按我的薄弱点出题 + 针对我的错题讲清楚 + 用我的资料出模拟卷」这条链路。这是「资料转物料」定位下的自然延伸。
